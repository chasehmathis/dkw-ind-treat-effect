# dkw: DKW and Makarov Bounds for Individual Treatment Effect Distributions

An R package implementing Dvoretzky-Kiefer-Wolfowitz (DKW) confidence bands for empirical cumulative distribution functions and Makarov bounds for individual treatment effect distributions.

## Installation

```r
# Install from local directory
devtools::install_github("chasehmathis/dkw-ind-treat-effect")

```

## Quick Start

```r
library(dkw)

# Simulate treatment and control outcomes
set.seed(123)
Y1 <- rnorm(100, mean = 1.5, sd = 1)  # Treatment group
Y0 <- rnorm(100, mean = 0, sd = 1)    # Control group

# Compute Makarov bounds on treatment effect distribution
result <- makarov_bounds(Y1, Y0, alpha = 0.1)

# Plot the bounds
plot_makarov_bounds(result$bounds_matrix)

# Extract quantile confidence intervals
quantile_ci <- extract_quantile_ci(result)
print(quantile_ci)
```

## Main Functions

### Computing Bounds

- **`makarov_bounds(Y1, Y0, alpha)`**: High-level function to compute Makarov bounds from raw data
- **`dkw_band(Fhat, alpha, n)`**: Compute standard DKW confidence bands
- **`hybrid_band(Fhat, alpha, m)`**: Compute hybrid Simes/Dempster/DKW bands (tighter in tails)
- **`extract_quantile_ci(result, quantiles)`**: Extract quantile confidence intervals

### Data Generation

- **`generate_potential_outcomes(m, p, tau, rho)`**: Simulate treatment/control data with bivariate normal potential outcomes
- **`get_bounds(m, p, alpha, rho, tau)`**: Generate data and compute DKW bounds in one step

### Visualization

- **`plot_makarov_bounds(bounds_matrix)`**: Plot Makarov bounds on treatment effect CDF
- **`plot_quantile_ci(result)`**: Plot quantile confidence interval comparison
- **`plot_dkw_bands(x, Fhat, lower, upper)`**: Plot DKW confidence bands

## Method Overview

The package implements:

1. **DKW Bounds**: Non-parametric confidence bands for empirical CDFs with the Massart tight constant
2. **Makarov Bounds**: Sharp bounds on the CDF of individual treatment effects τᵢ = Y(1)ᵢ - Y(0)ᵢ
3. **Hybrid Bounds**: Combination of Simes (upper) and Dempster (lower) methods for sharper confidence sets

The key insight is that while individual treatment effects are never observed (due to the fundamental problem of causal inference), valid bounds on their distribution can be derived from the marginal distributions of observed outcomes.

## Example: Full Analysis Pipeline

```r
library(dkw)

# 1. Generate simulated data with potential outcomes
data <- generate_potential_outcomes(
  m = 500,      # Sample size
  p = 0.5,      # Treatment proportion
  tau = 2,      # True average treatment effect
  rho = 0.3     # Correlation between potential outcomes
)

# 2. Extract observed outcomes by treatment status
Y1 <- data$Y[data$Z == 1]
Y0 <- data$Y[data$Z == 0]

# 3. Compute Makarov bounds
result <- makarov_bounds(Y1, Y0, alpha = 0.1)

# 4. Visualize
plot_makarov_bounds(result$bounds_matrix, true_tau = data$tau,
                    main = "Makarov Bounds vs True CDF")

# 5. Get quantile confidence intervals
ci <- extract_quantile_ci(result, quantiles = c(0.1, 0.25, 0.5, 0.75, 0.9))
print(ci)

# 6. Compare with true quantiles
true_quantiles <- quantile(data$tau, ci$quantile)
comparison <- data.frame(
  quantile = ci$quantile,
  lower_ci = ci$lower_ci,
  true_value = true_quantiles,
  covers = true_quantiles >= ci$lower_ci
)
print(comparison)
```
